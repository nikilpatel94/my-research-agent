# Research Agent

(The following content generated by [MAI-code-1-flash](https://microsoft.ai/models/mai-code-1-flash/) and reviewed by me.)


A customizable and extensible research agent built with Python, `deepagents`, and a skills-based workflow. It is designed to research a company or a domain using web search and page extraction, then return a structured result in a JSON schema that you define. Good and simple enough to integrate in webapps. Well atleast that was the plan by creating this that it has been helpful to me.

The project already includes:
- a reusable agent factory in `agent.py`
- tool definitions in `agent_tools.py`
- a domain use case in `company_research_usecase.py`
- skill files under `skills/` that guide the research workflow and output format

## Why this project exists

This agent is meant to be customized for different research tasks without rewriting the core orchestration logic. You can:
- add new tools as `@tool` functions
- define a new use case with its own system prompt and structured output model
- plug in skills that instruct the model how to research and format results
- scale it to company research, market research, competitor analysis, or internal knowledge gathering

## Core ideas

### 1) Tools
`agent_tools.py` defines the functions the model can call during a task. In this project, the default tools are web search and URL fetch via Tavily:

```python
from langchain.tools import tool
from tavily import TavilyClient

@tool
def web_search(query: str, max_results: int = 5) -> str:
    """Search the web and return search results."""
    tavily = TavilyClient()
    res = tavily.search(query, max_results=max_results)
    return "\n\n".join(
        f"{r['title']}\n{r['url']}\n{r['content']}"
        for r in res["results"]
    )

@tool
def fetch_url(url: str) -> str:
    """Fetch a page and return the text content."""
    tavily = TavilyClient()
    res = tavily.extract(urls=[url])
    if not res["results"]:
        return f"Could not fetch {url}"
    return res["results"][0]["raw_content"][:8000]
```

Add or replace tools here whenever you create a new research workflow.

### 2) Skills
The agent loads skills from the `skills/` folder. Skills are instructions that tell the agent how to behave in a problem domain. In this repo, they guide the agent to:
- verify the company domain matches the name
- search the web within a defined budget
- prioritize high-quality sources
- produce a strict JSON final output

This makes the agent easier to adapt for new workflows without touching the core runner.

### 3) Use cases
A use case binds together:
- a name for the workflow
- a model reference
- a system prompt
- a validation schema (Pydantic model)
- a user prompt

This is handled by `use_case.py`, and the example company workflow is `company_research_usecase.py`.

```python
from pydantic import BaseModel

class CompanyProfile(BaseModel):
    description: str
    employee_strength: str
    main_sector: str
```

The user prompt includes the company name and website, and the agent returns a JSON object matching the model.

## Setup

1. Create a virtual environment and install dependencies:

```bash
python -m venv .venv
. .venv/bin/activate   # Linux/macOS
# or .\.venv\Scripts\activate  # Windows PowerShell
pip install -r requirements.txt
```

2. Copy the sample environment file:

```bash
cp .env.example .env
```

3. Fill in the required values in `.env` using the keys defined in `.env.example`.

Required keys include:
- `ANTHROPIC_API_KEY`
- `OPENAI_API_KEY`
- `GOOGLE_API_KEY`
- `TAVILY_API_KEY`
- `DEFAULT_MODEL`

You can refer to `.env.example` for the exact keys and defaults.

## Customizing the agent

### Add a new tool
Open `agent_tools.py` and add another `@tool`-decorated function.

Example:

```python
from langchain.tools import tool

@tool
def news_search(query: str) -> str:
    """Search recent news articles for a given topic."""
    return f"News results for: {query}"
```

Then ensure the tool is returned by `get_all_tools()`.

### Add a new research use case
Create a new file, for example `market_research_usecase.py`, and follow the pattern used in `company_research_usecase.py`:

```python
from argparse import ArgumentParser
from pydantic import BaseModel
from use_case import Usecase

class MarketProfile(BaseModel):
    summary: str
    top_competitors: str
    market_size: str

SYSTEM_PROMPT = "You research a market using verified web sources."

# then create a `research()` function and invoke `Usecase(...)`
```

### Add or update skills
Create new folders/files under `skills/` and reference the skill path in `build_agent(..., skill_folder_path=...)` or update the example path used in `Usecase.build_agent()`.
